What we deliberately did NOT use

Not usedWhy
VPC, subnets, NAT GatewayNothing here needs a private network; NAT alone is ≈ $32/mo. All services are managed with public AWS endpoints, locked down by IAM + Cognito.
RDS / AuroraPer-hour cost even when idle. DynamoDB on-demand costs nothing when idle. Not planned.
Bedrock Agents (the managed service)Extra abstraction + cost; harder to debug. We implement the tool loop in the agent-chat Lambda with the Bedrock Converse API — same resume value ("built an agent with tool use"), full control.
Step FunctionsOur flow is short (parse → decide → save); a single Lambda is simpler. Add later if steps grow.
ECS / Fargate / EC2Always-on compute = always-on cost.
Secrets Manager, WAF, TextractSSM is free for our two keys; WAF is $5+/mo; emails are text, not scans.
